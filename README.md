# Online Voting System

## Overview
The Online Voting System is an innovative, web-based platform aimed at modernizing the voting process. It removes traditional obstacles, offering a more accessible and efficient experience for voters and administrators alike.

## Features
- **Secure Voter Registration:** Verification through Voter ID and personal credentials.
- **One Voter, One Vote:** Implementation of robust authentication to prevent duplicate voting.
- **Admin Dashboard:** Allows superadmins to manage candidates and monitor the election process.
- **Real-time Results:** Immediate and transparent display of voting outcomes.
- **User-Friendly Interface:** Designed for easy navigation by all users.

## Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Security:** Password Hashing, Input Validation

## Database Design
- **Voters Table:** Contains voter information.
- **Candidates Table:** Manages details of the candidates.
- **Votes Table:** Securely records individual votes.
- **Superadmin Table:** Manages administrative access.

## Usage
1. **Register:** Voters create accounts with valid credentials.
2. **Login:** Authorized access with encrypted passwords.
3. **Vote:** Select candidates from the list.
4. **View Results:** Results displayed post-voting.

## Security Measures
- **Input Validation:** Safeguards against SQL injection.
- **Password Hashing:** Secure storage of user passwords.
- **Session Management:** Protects confidentiality during voting.
